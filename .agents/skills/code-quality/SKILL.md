# Code Quality

Check:

- correctness
- duplication
- readability
- hidden coupling
- state handling
- error handling
- resource lifetime
- magic values
- inconsistent conventions
- unnecessary complexity
- API misuse
- dead code

Every finding must include evidence and a concrete recommended fix.
