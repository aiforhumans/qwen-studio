# Debugging

For each issue:

1. Reproduce or establish the failing path.
2. Trace inputs.
3. Trace state transitions.
4. Identify first incorrect behavior.
5. Separate symptom from root cause.
6. Define smallest safe fix.
7. Define regression test.

Avoid speculative fixes.
